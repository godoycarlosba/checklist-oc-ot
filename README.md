# Checklist OC / OT

App web simple para seguimiento de Órdenes de Compra y Órdenes de Trabajo en fabricación
(Oil & Gas / Viviendas Modulares).

## Características

- Carga manual de OCs y OTs con un clic.
- Tareas generales por OC + tareas por cada OT.
- Tareas generales por defecto: KOM, Presentación de pólizas, Presentación PIE Preliminar, Listado de documentos.
- Por cada OT: PL AESA, PL Cliente, Estado de Aprobación, PIE, Estado Aprobación PIE.
- Por cada tarea: responsable, fecha inicio, fecha fin.
- Exportar / Importar respaldo en JSON.
- Funciona 100% en el navegador (sin servidor) — datos en localStorage.

## Uso

Abrí `index.html` en cualquier navegador o visitá la URL de GitHub Pages.

## Tecnología

HTML + CSS + JavaScript vanilla, un solo archivo, cero dependencias.
